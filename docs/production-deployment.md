# Devcenter production deployment availability

Production deployment is not a public adoption path. The public chart can be inspected during an
evaluation, but an operational installation also needs private application images,
deployment-specific values, and a separate agreement with beyond10x. This page intentionally
provides status instead of a deployment call to action.

[Read the deployment boundary in the Devcenter guide](/docs/devcenter/#deployment-cli).
