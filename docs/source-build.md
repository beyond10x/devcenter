# Build the full Devcenter service from source

The full service-container path is available only to evaluators with approved access to Devcenter's
private sibling dependencies. The public source repository and frontend review do not grant that
access. The repository license permits a time-bounded evaluation; production, redistribution, and
post-trial use require a separate written agreement.

[Read the approved source-build requirements](/docs/devcenter/#run-the-full-service-container).
