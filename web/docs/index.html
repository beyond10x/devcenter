Devcenter documentation

Devcenter is an authenticated composition of independent agent, workflow, connector, identity, and execution services.

Authority

Identity establishes the actor and tenant. Connector Grants establish available external effects. Tasks and triggers carry revocable delegation references rather than browser credentials.

Model access

User-bound agents use a user-owned model connection held by Connectors. Service-bound agents use an operator-defined model route. Harness receives only the credential material required for the current provider attempt.

MCP

The /mcp endpoint projects the same governed operation catalog used by built-in agents. A client must authenticate through the configured Identity service.

Deployment

The public Helm chart is intentionally configuration-neutral. Supply tenant, hosts, immutable image references, storage, secret references, and any private Connector catalog bundle from a separate deployment repository.
